### Changed

- **A MIDI file no longer runs a note into the next on its key** (#104). `pieceMidi` wrote a note into the next one on its key and channel (`legato=` over 1, two lines on one key) as two overlapping notes, so the first note-off ended the second early. Now a note struck while its key sounds retriggers it. The ones before end at its start, and it sounds to the latest of their ends and its own, which is how yggi/webmidi's live MIDI out already sends it (`src/core/out.ts`). Notes struck at once on one key (a unison) are left as written, so a file read back keeps them. The events keep their lengths and no event snapshot moves; only the files' note-offs change. Of the 83 examples, 7 write different files, with the same notes and some note-offs moved: `clock` (5), `musicbox` (39), `echotape` (2), `pachelbel` (24), `idm` (1), `brothers` (48) and `tines` (4).
