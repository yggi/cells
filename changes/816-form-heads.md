### Repository

- **`ternary` and `rounded_binary` name their heads for themselves** (#816): their heads were both `&song`, the name the section kinds and song forms (#810) use for a song's intensity. They are `&ternary` and `&rounded_binary` now, as the other forms name theirs (`&period`, `&sentence`). A piece that takes one names its copy as it always did (`&twinkleSong from ternary(answer=&wonder) &twinkle`), so no piece changes and no event moves; the two fragments' text, and so their hashes, do (`ternary` `e2:9803c3c152d16a7b` → `e2:9575f0435e8469c5`, `rounded_binary` `e2:c65d9885ae13ce8a` → `e2:cfd868c5ac994008`), and a lockfile that holds either by its old hash plays the current text and the compile warns. Jambot takes both by id and names the copy itself, and neither frontend pins the old hashes.
