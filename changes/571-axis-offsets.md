### Changed

- **A style's axis is an offset chain, held to the axis** (#571, #881): a slot of a named style is a term of a sum of values, `&bite [&funk[bite] + &dsong + &dsect]` (`bite=&bite` on the style that reads it), the style's own value on the axis plus the levels above it, each a cell; before, `&funk[bite]` in a sum was read as a sound and refused. And a moving axis is held to its range wherever it is read: a sum past 1 reads 1, one below 0 reads 0, a plain cell above 1 reads 1 (before they read 1.2, or a negative sum as a bipolar share, `[.1 + -.3]` as .4). **What a frontend sees at its next pin:** nothing in a piece whose axes stay within 0 to 1, which is every example and fragment; a piece that wrote a moving axis outside it now reads the end of it. A stepped offset cell with a value below 0 still reads as a bipolar wave (decision 067 §5): write it from 0 up, or as a number cell.
