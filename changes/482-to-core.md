### Added

- **`toCore(source, options)`: a text in the core grammar** (decision 069, #482), for a machine reader (a hash, the learned layer, a comparison of two pieces), never for an editor. It runs Normalise, then de-sugars the rows the letters settle (comments, `from` written in place, units, note names, `&( … )`, `x!n`, table scans), folds with Shorten's core kinds and drops the lines nothing reads, and minifies the names it may rename (not the interface names, a drum's, or a drawing cell's until #481). It repeats until the text stops changing, and checks each step by S1. It returns `{ source, steps, left }`: `left` names the rows it hasn't rewritten yet (taps, subsequences, keys, meters, gates, `pitch=`, levels), which are its next rungs. Over every example it plays the same, is its own core, and is its normal form's core. Nothing a piece plays changes.
