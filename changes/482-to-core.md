### Added

- **`toCore(source, options)`: a text in the core grammar** (decision 069, #482), for a machine reader (a hash, the learned layer, a comparison of two pieces), never for an editor. It runs Normalise, then de-sugars the rows the letters settle (comments, `from` written in place, units, note names, `&( … )`, `x!n`, table scans; and, read from the compiled program, a tap of a note value as the meter's pulse with its chain, `16n` as `pulse*4` in 4/4 and `pulse*2` in 7/8, and a subsequence on its line's finest grid, `step=8n 0 [2 4]` as `step=8n*2 0@2 2 4`, where that plays the same), folds with Shorten's core kinds and drops the lines nothing reads, and minifies the names it may rename (not the interface names or a drum's). It repeats until the text stops changing, and checks each step by S1. It returns `{ source, steps, left }`: `left` names the rows it hasn't rewritten yet (keys, meters, gates, `pitch=`, levels, sliders, and a subsequence a finer grid would change), which are its next rungs. Over every example it plays the same, is its own core, and is its normal form's core. Nothing a piece plays changes.
