### Added

- **A repository told the ids it knows: use together across facets** (#716): `createRepository(fragments, { known })` takes a predicate for ids it doesn't hold but are fragments all the same, and `isLibraryFragment` (from `@yggi/cells/library`) is the library's. A frontend's repository of one facet's fragments (a rhythm's) then counts a use together with another's (a meter's) with no need to hold the other facet's fragments: a pair of known ids is counted, a query's `chosen` finds it, `useFragments` takes it (it moves no association of an id it only knows) and `Repository.knows(id)` says whether an id is held or known. An id neither held nor known is as before: left out of the merge (`Merged.unheld`) and refused by `useFragments`. A repository made with no `known` answers as it did.
