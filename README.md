# cells

A minimal language for music where everything is a cell: a helix with a braid in its grid, on top of Strudel's mini-notation. Text in, events out, with no host of its own.

```cells
&tune step=4 0 2 4 0 0 2 4 0 4 5 7@2 4 5 7@2 7 9 7 5 4 ~ 0 ~ 7 9 7 5 4 ~ 0 ~ 0!2 -5 0@2 0!2 -5 0@2
&voice s=sine loop=C4                           # a voice: a sine, on C4
&out loop=SAMPLE_RATE map=sample postgain=2 [&tune * &voice * .5]
```

That is Frère Jacques ([`examples/steps.cells`](examples/steps.cells)). One cell per line, attributes anywhere; a cell looped at an audio rate is a voice, and the sound card (`&out`) plays what is in its brackets.

## Use

It is the shared core of [Cell studio](https://github.com/yggi/cell-studio), the workbench, and [Jambot](https://github.com/yggi/jambot), the interactive, multi-user frontend, which depend on a tag, never a branch (what changed: [CHANGELOG.md](CHANGELOG.md)):

```json
"@yggi/cells": "github:yggi/cells#v0.3.0"
```

`compileSource` reads a piece, `planOf` makes what it plays, `windowAt` realizes a window of it as events; `createHost` answers the same as messages, in a worker or in node:

```ts
import { compileSource, planOf, windowAt } from '@yggi/cells';

const { ok, diagnostics } = compileSource(source); // the text's errors and warnings, with their lines
const events = windowAt(planOf(source), 0, 1).events; // the first second: { at, dur, voice, freq, gains, … }
```

The package ships TypeScript (Node won't strip it under `node_modules`: [#11](https://github.com/yggi/cells/issues/11)); a frontend's bundler reads it, and `types/` carries the declarations.
