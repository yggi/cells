# Decisions

One file per decision: `NNN-slug.md`, numbered in order, never renumbered. A record has a date, a status (proposed, accepted, superseded by NNN), the context, the decision and the consequences. Add its line to the list below, `NNN · the decision, in a sentence · → decisions/NNN-slug.md`, and the same in a few words to [../MEMORY.md](../MEMORY.md)'s list (a test checks both list every record).

The records here came from Cell studio with their numbers; the gaps are the workbench's decisions, which stay in [Cell studio's list](https://github.com/yggi/cell-studio/blob/main/docs/decisions/README.md). A new decision about the language takes the next number after the highest in either list, so a number names one decision across both.

Write a record when a choice has a rationale a later reader would otherwise have to rediscover (a rejected alternative, a trade-off). Don't write one for things the code or the language docs already say.
